# Security

If you find a security problem in this repository, the game or its website, please open an [issue](https://github.com/Deovandski/gassy-donkey/issues), or for anything sensitive use GitHub's [private vulnerability reporting](https://github.com/Deovandski/gassy-donkey/security/advisories/new) for this repository.

Secrets, signing keys and store identities never go in git: `.gitignore` covers the usual ones and CI fails if one is committed.
